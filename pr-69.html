Big picture

One mailbox symbol replaces the legacy reader

Issues #24 and #25 already publish and render presence in the ROM. Issue #26 joins those paths to the existing network client. The ROM source, submodule pin, mailbox layout and wire protocol version do not change.

How it works

Reconnect from a clean queue

A menu can leave old inbound messages queued through disconnect. The bridge keeps lua_connected clear after welcome until the ROM discards that queue, then clears every old slot and replays current peers.

Decisions in this PR

Preserve the contracts

Preserve v1 visibility explicitly

$ wire.visible = true
# The Me row still receives the original ROM state.
Why

The ROM's visible bit means controllable overworld; wire v1 means a running session, including menus and battles. The explicit conversion keeps the established protocol contract without game-struct reads. Reset closes the session instead of renewing an old one.
