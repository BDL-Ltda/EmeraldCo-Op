Big picture

The publisher is in the ROM, not the memory reader

Issue #21 chose the overworld hook. Issue #24 implements outbound publishing; #25's existing renderer stays in the same hook. The regular Lua bridge still reads game structs until #26 connects the mailbox to the socket.

How it works

Keep a snapshot only after a successful push

A full ring must not make the publisher forget an unsent change. It retries the latest state while the field hook runs. Idle has no ROM heartbeat; the network client's renewal is separate.

Under the hood

Exactly 13 bytes, already understood by Lua

These payload offsets come from CoopPresence, its compile-time assertions and docs/memory-map.md. The inbound remote slot is not part of this outbound payload.

Decisions in this PR

Preserve the agreed boundaries

Presence outside the renderer's callback guard

CoopPresence_Update();

Why

The publisher must observe the locked exit frame even if callback2 has changed. The renderer must not touch half-built field objects. This follows #21 and preserves the merged #25 path; the shared-hook regression checks both branches.
