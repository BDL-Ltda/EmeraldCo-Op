Big picture · How it works

A complete line is not yet a valid message

Issue #16 separates pure modules from thin emulator glue. The framer buffers incomplete byte chunks; the codec parses complete JSON text. Both run in plain Lua 5.4. Neither accesses game memory or creates connections.

Under the hood

Three values Lua must not collapse

A welcome with no players needs an array, not an object. Null must retain its slot instead of disappearing as Lua nil. Choose a shape to inspect the representation.

Decisions

Small, explicit contracts

Integer-only JSON

math.type(value) == "integer"
nil, error on unsupported data
Why

The issue asks for the protocol subset. Lua 5.4 integers preserve trainer IDs and timestamps exactly, including values beyond floating-point precision. Fractions and exponents are rejected, not rounded. Nesting is capped at 64 containers.

Bound the unfinished line

framing.new() -- 4096 bytes
framer:feed(bytes)
framer:finish() -- check EOF
Why

A large chunk is checked before its unfinished line is copied. Oversize input rejects the current batch and permanently fails the framer. A caller cannot accidentally resume a rejected stream.
