Big picture

A struct in RAM is the only channel between the game and the network

From milestone 0.4 the ROM owns co-op behavior and Lua is a dumb pipe between the mailbox and the socket (docs/architecture.md). This PR builds the mailbox and the ROM's side of it. The Lua side, publishing and rendering come in later issues.

How it works

One writer, one reader, slot first and index last

Each ring has one writer and one reader, so it needs no locks. The ROM writes only outbound.head and inbound.tail, and Lua writes only the other two indices. The writer fills slots[head] and then advances head. The reader copies slots[tail] and then advances tail. When (head + 1) % 16 == tail the ring is full and the message is dropped, so each ring holds at most 15 messages.

Decisions in this PR

The layout came from the issue. These details did not.

Issue #22 fixed the header, the slot size and the ring rules. These choices came up while implementing them.

Packed structs

src/coop/mailbox.c:10:14: error: size of array 'CoopMailboxRingSize' is negative
struct __attribute__((packed)) CoopMailboxRing
Why

The modern build uses -mabi=apcs-gnu, which aligns every struct to 4 bytes. That put slots at offset 4 instead of 2. The static asserts failed the first build, which is their job. Packing all three structs restores the agreed layout. Copies use memcpy because packed structs have 1-byte alignment.

A compiler barrier, but no lock

#define COOP_MAILBOX_BARRIER() asm volatile("" ::: "memory")
Why

mGBA's frame callback runs at the frame boundary, which can land in the middle of a ROM call. If GCC moved the head store before the slot stores, Lua could read a half-written slot. The barrier keeps "slot first, index last". It emits no instructions.

Init in AgbMain, every boot

InitHeap(gHeap, HEAP_SIZE);
CoopMailbox_Init();
Why

The issue asks for one call at boot. AgbMain also runs after a soft reset, so the mailbox comes back zeroed with lua_connected cleared. The Lua client (#23) should treat a missing magic or a cleared rom_ready as a reset.
