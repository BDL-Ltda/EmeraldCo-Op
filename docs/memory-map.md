# Memory map

Status: documentation stub. No global addresses or struct offsets are defined here yet.

[Issue #9](https://github.com/DaviAlencastro/EmeraldCo-Op/issues/9) will document the game state needed by the Lua client and the relevant offsets sourced from the decompilation headers. Global addresses must come from **`client/addresses.lua`**, generated by **`cmd/symgen`** from the ROM build's ELF. Never hand-write or guess addresses.

The 0.4+ **`gCoopMailbox`** design is recorded in [architecture.md](architecture.md). Its exact memory layout will be documented here when implemented; the planned header and two 16-slot rings do not establish offsets or a binary contract yet.

Any ROM change must rebuild the ROM, regenerate `client/addresses.lua`, and update this document if the memory layout changes, all in the same pull request.
